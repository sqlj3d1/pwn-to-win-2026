./scoring_format
Knowing how points work changes how you prioritise challenges during the competition.
📋
Static Scoring

Each challenge has a fixed point value that never changes. Every team that solves it gets the same points — no advantage for solving early.

📉
Dynamic / Decaying Scoring

Challenges start at max points. Each time a team submits the correct flag, the value drops for everyone. Solve early = more points. Most modern CTFs use this.

⚔️
Attack & Defense Scoring

Points awarded for successfully breaching opponents' systems. Points deducted if your own system gets compromised. Offense and defense run simultaneously.
